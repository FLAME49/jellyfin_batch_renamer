# أداة إعادة تسمية ملفات Jellyfin

تطبيق سطح مكتب لتنظيم مكتبة المسلسلات من خلال إعادة تسمية ملفات الفيديو والترجمة دفعة واحدة بصيغة متوافقة مع Jellyfin.

## الميزات الرئيسية

- إعادة تسمية ملفات الفيديو والترجمة دفعة واحدة.
- مطابقة الفيديو والترجمة تلقائيًا حسب ترتيب القائمتين.
- إنشاء أسماء حلقات متوافقة مع Jellyfin مثل `S02E01` و`Series Name - S02E01`.
- دعم صيغ الفيديو: `mp4` و`mkv` و`avi` و`mov` و`wmv` و`flv` و`webm` و`m4v` و`ts`.
- دعم صيغ الترجمة: `srt` و`ass` و`vtt` و`sub` و`ssa` و`idx`.
- البحث الاختياري داخل المجلدات الفرعية.
- ترتيب طبيعي لأسماء الملفات والحلقات المرقمة.
- إعادة ترتيب ملفات الفيديو والترجمة يدويًا بالسحب والإفلات.
- معاينة جميع التغييرات قبل تنفيذ إعادة التسمية.
- اكتشاف تعارض الأسماء وتنفيذ العملية بطريقة آمنة.
- حفظ آخر عملية لإتاحة التراجع حتى بعد إعادة تشغيل البرنامج.
- واجهة باللغتين العربية والإنجليزية.
- وضعان نهاري وليلي مع حفظ آخر إعدادات مختارة.

## التثبيت

### المتطلبات

- Python 3.10 أو أحدث
- Windows أو Linux أو macOS

### 1. تنزيل المشروع

نزّل ملف المشروع وفك ضغطه، ثم افتح نافذة الأوامر داخل مجلد البرنامج.

### 2. إنشاء بيئة افتراضية

```bash
python -m venv .venv
```

### 3. تفعيل البيئة الافتراضية

**Windows PowerShell**

```powershell
.venv\Scripts\Activate.ps1
```

**Windows Command Prompt**

```bat
.venv\Scripts\activate.bat
```

**Linux أو macOS**

```bash
source .venv/bin/activate
```

### 4. تثبيت المتطلبات

```bash
pip install -r requirements.txt
```

### 5. تشغيل البرنامج

```bash
python main.py
```

## الاستخدام

1. اختر المجلد الذي يحتوي على ملفات الموسم أو الحلقات.
2. فعّل **البحث في المجلدات الفرعية** إذا كانت الملفات موزعة داخل مجلدات فرعية.
3. راجع قائمتي الفيديو والترجمة بعد ترتيبهما تلقائيًا.
4. اسحب العناصر لتصحيح ترتيبها عند الحاجة.
5. أدخل الموسم مثل `S02`، ثم أدخل اسم المسلسل اختياريًا.
6. اضغط **تغيير الأسماء** وراجع المعاينة الكاملة.
7. أكّد العملية لتغيير أسماء الملفات.
8. استخدم **تراجع عن آخر عملية** لاستعادة الأسماء السابقة. يبقى التراجع متاحًا بعد إعادة تشغيل البرنامج.

## قاعدة البيانات المحلية

توجد قاعدة بيانات SQLite باسم `rename_history.db` داخل مجلد البرنامج، وتحتوي على:

- سجل آخر عملية إعادة تسمية ناجحة.
- آخر لغة مختارة.
- آخر وضع ليلي أو نهاري مختار.

يُحذف سجل إعادة التسمية بعد نجاح التراجع. مكتبة SQLite مدمجة مع Python ولا تحتاج إلى تثبيت مكتبة إضافية.

## ملاحظات الأمان

- يعيد البرنامج تسمية الملفات داخل مجلداتها الأصلية ولا ينقلها.
- يتجاهل الملفات غير المتعلقة، مثل الصور وملفات NFO.
- يمنع التنفيذ عند وجود اسم هدف متعارض.
- يستخدم أسماء مؤقتة لمنع التصادم أثناء تبديل الأسماء.
- إذا فشلت إحدى خطوات العملية، يحاول البرنامج استعادة الأسماء الأصلية.
